# AI ML Roadmap — iPhone Web App

This is a phone-first PWA version of the roadmap.

Features:
- Today's Target at top
- Circular AI/ML completion
- Done → Next Day
- Move Ahead
- Reschedule
- 2 NeetCode questions/day
- NC number + LeetCode number + difficulty + pattern
- 10-question mastery checkpoint after each completed DSA category
- Sections 1–64 study source, certification/proof, research reading, project and revision
- Export/import progress backup
- Offline cache after the first successful web load

IMPORTANT:
A PWA must be served from HTTPS (or localhost during development). Do not open index.html directly from the Files app on iPhone and expect full PWA installation.

Recommended hosting:
1. Create a GitHub repository, e.g. ai-ml-roadmap.
2. Upload all files/folders from this directory.
3. Enable GitHub Pages for the repository.
4. Open the resulting HTTPS URL in Safari on iPhone.
5. Share → Add to Home Screen → turn on Open as Web App → Add.

Your progress is stored locally on that phone/browser. Export a backup from More → Export backup when you want a portable copy.
